# 浸水予測AIイメージ（九州）— GitHub公開の手順（初めての方向け）

このフォルダ一式を GitHub に置くと、URLを開くだけで画面を使えるようになります（パスワード付き）。

> 注意：無料の公開リポジトリを使う前提です。**画面はパスワードで保護**します（関係者に共有する1つのパスワード）。ただし、リポジトリ内のファイル（画面のコードや、置いた雨量データ）は、リポジトリのURLを知っている人なら読めます。**架空データのイメージ（MoC）用途に限り**使ってください。実際の施設の位置や運用データは載せないでください。

---

## 手順

### 1. GitHub のアカウントを作る
1. https://github.com を開き、右上の **Sign up** からメールアドレス・パスワード・ユーザー名を登録します。
2. 届いた確認メールのコードを入力して完了です。

### 2. リポジトリ（作品の入れ物）を作る
1. ログイン後、右上の **＋** → **New repository**。
2. **Repository name** に半角英数字で名前を入力（例：`flood-map`）。
3. **Public** を選ぶ。
4. **Add a README file** にチェックを入れる。
5. **Create repository** を押す。

### 3. ファイルをアップロードする
1. 作ったリポジトリの画面で **Add file → Upload files**。
2. この zip を解凍したフォルダの中の、次をドラッグ＆ドロップします。
   - `index.html`
   - `data` フォルダ
   - `robots.txt`
   - `.nojekyll`（見えない場合は省略可）
   - `README.md`（上書きしてよい）
3. 下の **Commit changes** を押す。

### 4. 自動公開の設定ファイルを作る（ここだけ手作業）
`.github` というフォルダは、パソコンで隠れていてドラッグできないことがあるため、画面上で作ります。
1. リポジトリの画面で **Add file → Create new file**。
2. ファイル名の欄に、次をそのまま入力します（`/` を打つとフォルダになります）。
   `.github/workflows/site.yml`
3. 本文の欄に、zip 内の **`github_workflow_site.yml`** の中身をすべてコピーして貼り付ける。
4. **Commit changes** → **Commit changes** を押す。

### 5. パスワードを登録する（画面を開くときのパスワード）
1. リポジトリの **Settings** → 左メニュー **Secrets and variables** → **Actions**。
2. **New repository secret** を押す。
3. **Name** に `PAGE_PASSWORD`（そのまま入力）、**Secret** に開くときのパスワードを入力する。
   - 12文字以上の、推測されにくい文字列にしてください。
   - 他の場所で使っているパスワードは使わないでください。
4. **Add secret** を押す。

### 6. サイトの公開を有効にする
1. リポジトリの **Settings** → 左メニュー **Pages**。
2. **Build and deployment** の **Source** を **GitHub Actions** にする。

### 7. 初回の実行
1. リポジトリの **Actions** タブを開く（初回は有効化のボタンが出たら押す）。
2. 左の **サイトを公開（パスワード付き）** → **Run workflow** → 緑の **Run workflow**。
3. 数分待ち、緑のチェックになれば成功です。
4. 公開URL： `https://（あなたのユーザー名）.github.io/（リポジトリ名）/`

### 8. 動作の確認
- 公開URLを開くと、パスワードの入力画面が出ること（入力すると画面が開きます）。

## 過去の雨量データ（CSV）を置く
気象庁から配信されている期間（直近数日）より古い時刻を画面で見たいときは、自分でダウンロードしたCSVを置きます。
1. 気象庁「過去の気象データ・ダウンロード」（https://www.data.jma.go.jp/risk/obsdl/index.php）で、見たい観測所（複数可）・期間・「降水量」の時別値を選んでCSVをダウンロードします。
2. ファイル名を `YYYYMM.csv`（例：`202607.csv`）にして、リポジトリの `data/obs/` フォルダにアップロードします（Add file → Upload files）。月をまたぐ期間は、月ごとに分けてください。
3. アップロードすると自動で公開し直されます。画面の「基準時刻」でその日時を選ぶと、雨量が表示されます。
詳しい書き方は `data/obs/README.txt` を見てください。

## 更新するとき
- ファイルを差し替える（Add file → Upload files → Commit changes）と、自動で公開し直されます。
- パスワードを変えるときは、`PAGE_PASSWORD` を更新し、Actions から **Run workflow** をやり直します。

## うまくいかないとき
- **「PAGE_PASSWORD が未設定です」と出て失敗する**：手順5を行ってください。パスワードなしでは公開されない仕組みです。
- **Actions が赤（失敗）になる**：失敗した実行をクリックし、赤い手順のメッセージをコピーして、Claude に貼って相談してください。

## 補足
- 検索エンジンに載せない指定（noindex・robots.txt）も入れています。ただしこれは「お願い」であり、守りの本体はパスワードです。
- パスワードは画面を開くときの1つだけで、個人ごとのログインではありません。漏れたら変更してください。
- 気象庁データの出典表記は、画面に残してください（出典：気象庁）。
